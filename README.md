# 🌱 AgriAssist Pro

## AI-Powered Agriculture Platform for Rwanda & Africa

AgriAssist Pro is a smart farming platform that uses AI, weather intelligence, crop information, disease awareness, and market insights to help farmers make better decisions.

## 🚀 Features

✅ AI Farmer Assistant  
✅ Crop Search  
✅ Crop Disease Information  
✅ Weather Intelligence  
✅ Market Price Dashboard  
✅ Interactive Charts  
✅ Farming Recommendations  
✅ Dark Mode  
✅ Mobile Responsive Design  

## 🛠 Technologies

- Python
- Flask
- HTML/CSS
- JavaScript
- Chart.js
- OpenWeather API
